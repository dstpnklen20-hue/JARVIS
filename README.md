# Джарвис

Голосовой ассистент для Windows по мотивам Iron Man: слушает микрофон в фоне, откликается на
«Джарвис», выполняет команды и работает офлайн. Ядро написано на Rust, нейросети — sherpa-onnx.

> **Статус: этап 3 (разрешения).** Джарвис живёт в трее, откликается на «Джарвис», узнаёт ваш
> голос и выполняет команды из `commands/` — но каждую новую команду сначала спрашивает
> разрешения. Есть журнал действий и аварийная остановка. Программы, скрипты и клавиши — этап 4.
> План — `JARVIS_SPEC.md`, раздел 11; история решений — `docs/DEVELOPMENT.md`.

## Требования

- Windows 10 (1809+) или Windows 11, x64.
- Rust stable (MSVC) и Visual Studio Build Tools с компонентом «Разработка классических приложений на C++».
- Микрофон. Лучше гарнитура: микрофон у рта и меньше эха (особенно для игрового режима).

## Установка

### 1. Инструменты

```powershell
winget install --id Microsoft.VisualStudio.2022.BuildTools -e --override "--quiet --wait --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
winget install --id Rustlang.Rustup -e
```

Откройте новый терминал и проверьте: `cargo --version`.

### 2. Модели и библиотеки — до первой сборки

```powershell
.\scripts\download-models.ps1          # обязательное (~175 МБ)
.\scripts\download-models.ps1 -Full    # плюс необязательное (TEN VAD)
```

Скрипт скачивает файлы с докачкой при обрыве, сверяет SHA-256 с `scripts/assets.json` и кладёт в
`models/` и `lib/`. Уже установленное пропускается, `-Force` переустанавливает. Если PowerShell
запрещает скрипты: `powershell -ExecutionPolicy Bypass -File .\scripts\download-models.ps1`.

| Ресурс | Зачем |
|---|---|
| sherpa-onnx 1.13.8 (архив библиотеки) | движок нейросетей; сборка берёт его отсюда, а не качает сама без проверки |
| Zipformer small-ru (Vosk, 2025) | потоковое распознавание русской речи: «Джарвис», позже команды |
| Silero VAD | детектор речи: начало и конец фразы |
| CAM++ | распознавание говорящего: Джарвис откликается только на вас |
| TEN VAD | альтернативный детектор речи (необязательно) |

### 3. Сборка и проверка

```powershell
cargo build --release
.\target\release\jarvis.exe --check
```

`--check` проверяет ОС, права, конфиг, микрофон (и что от него идёт звук), модели, звуковой пакет и
образец голоса. Код возврата не 0, если есть ошибка.

### 4. Ваш голос (рекомендуется)

```powershell
.\target\release\jarvis.exe --enroll
```

Скажите «Джарвис» 5 раз с обычного места. Джарвис запомнит ваш голос (`data/voiceprint.json`, в git
не попадает) и будет откликаться только на него — не на телевизор и не на гостей. Без образца он
откликается на любой голос.

## Запуск

```powershell
.\target\release\jarvis.exe            # значок появится в трее
.\target\release\jarvis.exe --stop     # мягко остановить работающего Джарвиса
```

Цвет значка: зелёный — жду «Джарвис»; синий — слушаю команду; серый — пауза (микрофон
освобождён); жёлтый — загрузка; красный — проблема со слухом (подробности — в подсказке и в логе).
Меню значка: «Пауза», «Выход». Запускается только одна копия.

Прочие режимы:

| Команда | Что делает |
|---|---|
| `jarvis --check` | проверка окружения |
| `jarvis --enroll` | запись образца голоса с микрофона |
| `jarvis --enroll-from a.wav b.wav c.wav` | образец голоса из WAV (по одному «Джарвис» в файле) |
| `jarvis --bench [файлы.wav]` | замеры: «Джарвис» (задержка, нагрузка, сходство голоса) и команды (верно ли и когда решено); без файлов — `tests/fixtures` |
| `jarvis --record out.wav --seconds 5` | отладка: записать, что слышит модель (по умолчанию звук на диск не пишется) |
| `jarvis --root F:\JARVIS` | явно указать корень проекта |

## Настройка

- `config/default.toml` — значения по умолчанию с комментариями. Лежит в git, не меняйте его.
- `config/user.toml` — ваши изменения: только нужные ключи, в тех же секциях. В git не попадает.

```toml
# config/user.toml
[audio]
input_device = "Fuxi-H3"   # часть имени микрофона; "default" — системный

[wake]
max_edit_distance = 1      # 0 — строже, 2 — чувствительнее
listen_secs = 8

[nlu]
min_score = 0.8            # строже сопоставлять фразы с командами

[speaker]
threshold = 0.45           # или "auto" — подобранный при --enroll
```

С ошибкой в конфиге Джарвис не стартует и пишет, какой параметр неверен и почему.

Логи: `logs/jarvis.ГГГГ-ММ-ДД.log`, ротация раз в сутки. Подробнее: `logging.level = "debug"` или
переменная `RUST_LOG=debug`; что именно распознаётся — `RUST_LOG=info,jarvis_audio=trace`.

## Звуковые пакеты

Пакет — папка в `sounds/` с WAV-файлами и `pack.toml`:

```toml
name = "Мой Джарвис"
[replies]
wake = ["yes_sir.wav", "listening.wav"]     # обязательно: отклик на «Джарвис»
ok = ["done.wav"]                           # «Запрос выполнен, сэр»
not_understood = ["sorry.wav"]              # «Не понял, сэр»
failed = ["failed.wav"]                     # «Не удалось, сэр»
ask = ["may_i.wav"]                         # «Сэр, разрешите выполнить?»
denied = ["as_you_wish.wav"]                # «Как скажете, сэр» (после отказа)
```

На ответ можно положить несколько вариантов — они чередуются. Тишина по краям файлов обрезается
автоматически. Выбор пакета: `voice.pack` в конфиге. Стандартный пакет сделан голосом Windows
«Pavel»; пересоздать или сделать свой другим голосом: `scripts\generate-voice-pack.ps1 -Voice Irina -Name irina`.

## Как пользоваться

- «Джарвис» → «Да, сэр» → команда: «открой ютуб».
- Можно на одном дыхании: «Джарвис, открой ютуб».
- После команды 12 секунд (`session.follow_up_secs`) можно говорить следующую без «Джарвис»:
  «включи музыку», «громче».
- Непонятная фраза после «Джарвис» — «Не понял, сэр». Непонятная фраза в режиме ожидания
  следующей команды игнорируется (вдруг это разговор в комнате).
- Команда часто выполняется ещё до конца фразы: когда начало фразы уже однозначно («открой ю…»).

### Разрешения

Перед командой, которую вы ещё не разрешали, Джарвис спрашивает: «Сэр, разрешите выполнить?» — и
показывает окно с подробностями (что именно произойдёт: какой сайт, какая клавиша). Ответьте голосом
или кнопкой:

| Ответ | Что будет |
|---|---|
| «да», «разрешаю» | выполнить один раз, в следующий раз спросить снова |
| «всегда», «разрешаю всегда» | выполнить и больше не спрашивать |
| «нет», «отмена» | не выполнять |
| «никогда» | не выполнять и запомнить запрет |
| молчание 10 секунд | не выполнять |

- Решения хранятся в `config/permissions.toml` (ваш файл, в git не попадает). Пакеты команд выдать
  себе разрешение не могут.
- Разрешение привязано к действию: изменится адрес или путь в команде — Джарвис спросит снова.
- Команды с пометкой `always_ask = true` спрашивают каждый раз; снять пометку можно только вам —
  `allow_always = true` у команды в `permissions.toml`.
- Забыть все разрешения: «Джарвис, забудь разрешения» (с подтверждением) или пункт в трее.

### Аварийная остановка

**Ctrl+Alt+F12** (настраивается: `hotkeys.emergency_stop`) или «Джарвис, стоп» / «хватит»:
Джарвис замолкает, отменяет текущее действие и вопрос и ставит слух на паузу (микрофон освобождается).
Продолжить — снять «Паузу» в трее.

### Журнал действий

`logs/actions.ГГГГ-ММ-ДД.jsonl` — по строке на каждую команду: время, что услышано, какая команда,
уверенность, было ли разрешение и как получено (голосом или кнопкой), результат.

Готовые команды:

| Пакет | Фразы |
|---|---|
| browser | открой ютуб · открой гугл · открой яндекс |
| media | включи музыку / поставь на паузу · следующий трек · предыдущий трек · громче · тише · выключи звук |

## Как добавить свою команду

Команды — TOML-файлы, код менять не нужно. Пакет — папка в `commands/` с файлом `command.toml`:

```toml
pack = "my"          # имя пакета
version = 1

[[command]]
id = "open_mail"                      # латиница, цифры, _ и -; уникален среди всех пакетов
phrases = ["открой почту", "проверь почту"]
description = "откроет Gmail в браузере"   # читается в вопросе-разрешении: «команда X <description>»
reply = "ok"                          # ответ после успеха: ok, failed, not_understood, wake, ask, denied или none
# always_ask = true                   # спрашивать разрешение каждый раз
[command.action]
type = "open_url"
url = "https://mail.google.com"
```

Типы действий:

```toml
# Открыть сайт (только http:// и https://)
[command.action]
type = "open_url"
url = "https://www.youtube.com"

# Мультимедиа-клавиши: play_pause, next, previous, stop, volume_up, volume_down, mute
[command.action]
type = "media"
operation = "volume_up"
steps = 5            # только для громкости: нажатий по ~2 %, 1–50 (по умолчанию 5)

# Сказать готовый ответ из звукового пакета или свой WAV из папки пакета
[command.action]
type = "say"
reply = "ok"         # или: file = "hello.wav"
```

Программы, скрипты, клавиши для игр, питание, цепочки действий — на этапе 4.

Советы по фразам:
- Пишите так, как говорите, по-русски: «открой ютуб», а не «YouTube». Регистр, «ё», знаки
  препинания и слова-паразиты («ну», «пожалуйста») не важны; числа можно словами.
- Порядок слов не важен: «ютуб открой» тоже сработает.
- Две команды с одинаковой фразой — предупреждение в логе и в `jarvis --check`.
- Ошибка в манифесте не ломает остальные: пакет пропускается, в логе — файл, строка и причина.
  Проверка: `jarvis --check` (пункт «Команды»).
- Чтобы потренироваться без последствий — `general.dry_run = true`: команды распознаются и
  пишутся в лог, но не выполняются.

## Игровой режим

Играйте в наушниках: иначе микрофон слышит звук игры, и распознавание заклинаний ухудшается.

## Структура

```
crates/
  jarvis-core/       конфиг, логи, ресурсы, автомат состояний, манифесты команд
  jarvis-audio/      захват звука, ресемплинг, слово активации, распознавание команд, VAD, голос, звуки
  jarvis-nlu/        нормализация текста, числа словами, нечёткое сопоставление с фразами
  jarvis-actions/    исполнители действий (open_url, media, say)
  jarvis-platform/   Windows API: ОС, права, одна копия, цикл сообщений, Ctrl+C, --stop, ShellExecute, SendInput
  jarvis-app/        бинарник jarvis: трей, ядро, разбор команд, --check/--bench/--enroll/--record
commands/            пакеты команд (browser, media)
config/              default.toml (в git), user.toml и permissions.toml (ваши, не в git)
sounds/default/      стандартный звуковой пакет
scripts/             скачивание моделей (assets.json — URL и SHA-256), генерация звуков и тестовых записей
tests/fixtures/      синтетические WAV для тестов (wake, negative, enroll)
docs/DEVELOPMENT.md  журнал разработки и принятых решений
models/, lib/, data/ скачанное и личное (не в git)
```

## Решение проблем

| Симптом | Что делать |
|---|---|
| `cargo` не найден | Откройте новый терминал после установки Rustup или добавьте `%USERPROFILE%\.cargo\bin` в PATH. |
| `link.exe not found` при сборке | Не установлены Build Tools с компонентом C++ (шаг 1). |
| Сборка: `SHERPA_ONNX_ARCHIVE_DIR does not contain expected archive` | Сначала `scripts\download-models.ps1` (шаг 2). |
| `--check`: «не скачано» / «нет метки» | `scripts\download-models.ps1` (при повреждении — с `-Force`). |
| `--check`: «цифровая тишина» | Микрофон выключен кнопкой на устройстве или в драйвере; проверьте в «Параметры → Система → Звук». |
| `--check`: микрофон не найден | `audio.input_device` — подстрока имени из списка «устройства ввода». |
| Значок красный «не слышу» | Микрофон отключили — Джарвис сам переподключится, когда он появится. |
| Не реагирует на «Джарвис» | `jarvis --record test.wav`, скажите «Джарвис», затем `jarvis --bench test.wav` — видно, что слышит модель. Если голос не совпал — в логе «сказал не ваш голос»: перезапишите `--enroll` или понизьте `speaker.threshold`. |
| Загрузка модели оборвалась | Запустите скрипт ещё раз — скачивание продолжится. |
| «файл разрешений не читается» | Исправьте `config/permissions.toml` по сообщению или удалите его — Джарвис снова начнёт спрашивать. |
| «горячая клавиша … уже занята» | Её заняла другая программа — выберите другую в `hotkeys.emergency_stop`. |
| Команда не выполняется без вопроса | Это не ошибка: вы ответили «никогда». Скажите «Джарвис, забудь разрешения» или удалите запись в `permissions.toml`. |
