# Джарвис

Голосовой ассистент для Windows по мотивам Iron Man: слушает микрофон в фоне, откликается на
«Джарвис», выполняет команды и работает офлайн. Ядро написано на Rust, нейросети — sherpa-onnx.

> **Статус: этап 8 (упаковка).** Джарвис живёт в трее, откликается на «Джарвис», узнаёт ваш
> голос и выполняет команды из `commands/`: сайты, программы, скрипты, клавиши, питание, цепочки,
> параметры из речи («громкость на 40»). Каждую новую команду сначала спрашивает разрешения.
> Свободные вопросы — нейросети Claude (нужен ключ API). Есть установщик и автозапуск.
> План — `JARVIS_SPEC.md`, раздел 11; история решений — `docs/DEVELOPMENT.md`.

## Требования

- Windows 10 (1809+) или Windows 11, x64.
- Rust stable (MSVC) и Visual Studio Build Tools с компонентом «Разработка классических приложений на C++».
- Микрофон. Лучше гарнитура: микрофон у рта и меньше эха (особенно для игрового режима).

## Установка готовой программы

`JarvisSetup.exe` (~120 МБ): установка для текущего пользователя, без прав администратора, в
`%LOCALAPPDATA%\Programs\Jarvis`. Внутри — программа, команды, стандартный звуковой пакет и всё
нужное для работы (распознавание, детекторы речи, голос Dmitri); другие голоса —
`scripts\download-models.ps1 -Full` в папке программы. Галочки: «Запускать при входе в Windows»
(по умолчанию включена), «Ярлык на рабочем столе». В меню «Пуск» — «Джарвис» и «Остановить Джарвиса».

- Обновление — новый установщик поверх: работающий Джарвис останавливается сам; ваши
  `config\user.toml`, `config\permissions.toml`, `data\`, `logs\`, `commands\my\` не трогаются.
- Удаление — «Параметры → Приложения»: убирает установленные файлы и автозапуск; ваши файлы
  остаются в папке.
- После установки — `jarvis.exe --check` и `jarvis.exe --enroll` (шаг 4 ниже) из папки программы.

Собрать установщик самому: `.\scripts\build-installer.ps1` (нужен Inno Setup 6:
`winget install --id JRSoftware.InnoSetup -e --scope user`) → `target\installer\JarvisSetup.exe`.
Личное (голос Джарвиса, `commands\my`) в него не попадает; `-Personal` добавит их —
`JarvisSetup-personal.exe` только для своего компьютера, никому не передавать.

## Установка из исходников

### 1. Инструменты

```powershell
winget install --id Microsoft.VisualStudio.2022.BuildTools -e --override "--quiet --wait --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
winget install --id Rustlang.Rustup -e
```

Откройте новый терминал и проверьте: `cargo --version`.

### 2. Модели и библиотеки — до первой сборки

```powershell
.\scripts\download-models.ps1          # обязательное (~240 МБ)
.\scripts\download-models.ps1 -Full    # плюс необязательное (TEN VAD, ещё три голоса)
```

Скрипт скачивает файлы с докачкой при обрыве, сверяет SHA-256 с `scripts/assets.json` и кладёт в
`models/` и `lib/`. Уже установленное пропускается, `-Force` переустанавливает. Если PowerShell
запрещает скрипты: `powershell -ExecutionPolicy Bypass -File .\scripts\download-models.ps1`.

| Ресурс | Зачем |
|---|---|
| sherpa-onnx 1.13.8 (архив библиотеки) | движок нейросетей; сборка берёт его отсюда, а не качает сама без проверки |
| Zipformer small-ru (Vosk, 2025) | потоковое распознавание русской речи: «Джарвис», позже команды |
| Silero VAD | детектор речи: начало и конец фразы |
| CAM++ | распознавание говорящего: Джарвис откликается только на вас |
| Голос Dmitri (Piper) | синтез речи: вопросы-разрешения и уточнения вслух |
| TEN VAD | альтернативный детектор речи (необязательно) |
| Голоса Irina, Ruslan, Denis | другие голоса синтеза (необязательно) |

### 3. Сборка и проверка

```powershell
cargo build --release
.\target\release\jarvis.exe --check
```

`--check` проверяет ОС, права, конфиг, микрофон (и что от него идёт звук), модели, звуковой пакет,
синтез речи (пробной фразой) и образец голоса. Код возврата не 0, если есть ошибка.

### 4. Ваш голос (рекомендуется)

```powershell
.\target\release\jarvis.exe --enroll
```

Скажите «Джарвис» 5 раз с обычного места. Джарвис запомнит ваш голос (`data/voiceprint.json`, в git
не попадает) и будет откликаться только на него — не на телевизор и не на гостей. Без образца он
откликается на любой голос.

## Запуск

**Проще всего — `jarvis-start.cmd`** в корне проекта (двойной щелчок): запускает Джарвиса, а если
он уже работает — перезапускает (останавливает, ждёт, запускает заново). Нужна собранная
release-версия (`cargo build --release`).

```powershell
.\target\release\jarvisw.exe           # без окна консоли — значок появится в трее
.\target\release\jarvis.exe            # то же, но с консолью (видно лог)
.\target\release\jarvis.exe --stop     # мягко остановить работающего Джарвиса
```

`jarvisw.exe` — запуск без консоли (его используют ярлыки, автозапуск и `jarvis-start.cmd`):
запускает рядом лежащий `jarvis.exe` скрыто и передаёт ему аргументы.

**Главное окно** — щелчок по значку в трее, пункт меню «Открыть Джарвиса» или повторный запуск
(ярлык «Джарвис», когда он уже работает). В центре — реактор: цвет — состояние, пульсирует от
голоса Джарвиса и от вашей речи после «Джарвис»; под ним — что он расслышал. Внизу — микрофон,
нейросети, память и процессор. Вкладки:
- **Команды** — все команды с фразами и разрешением: щелчок по разрешению меняет его по кругу
  «Спрашивать → Всегда → Никогда»; «Каждый раз» — команда помечена автором `always_ask`.
  **«+ Новая» и «Изменить»** — редактор команд: фразы, что сделает, действие (открыть сайт,
  запустить программу — кнопка «Выбрать…», сочетание или клавиша, музыка и громкость, фраза
  Джарвиса), ответ, «спрашивать каждый раз». Команды пишутся в личный пакет `commands\my`
  (стандартные пакеты — только чтение: их перезаписывает обновление); перед записью проверяются
  тем же загрузчиком — ошибка показывается, файл не меняется; подхватываются сразу. Цепочки,
  вопросы, скрипты и параметры из речи («громкость на {level}») правятся в `command.toml`.
  **«Журнал»** — последние 100 действий: что расслышал, какая команда, как получено разрешение,
  результат.
- **Настройки** — микрофон, ожидание следующей команды, «только мой голос» и строгость
  проверки, звуковой пакет, голос синтеза, громкость, нейросеть, ключ API, автозапуск,
  приветствие, горячая клавиша аварийной остановки, режим отладки (команды распознаются и
  пишутся в журнал, но не выполняются). «Сохранить» пишет только изменённое в
  `config\user.toml` (ваши комментарии остаются), «Перезапустить» применяет. Ключ API — в
  Диспетчере учётных данных Windows.

Закрытое окно не занимает память; Джарвис продолжает работать в трее. Окно — страница в
WebView2 (есть в Windows 11), в интернет не ходит. `jarvis --restart` — перезапуск из терминала.

Значок — дуговой реактор, цвет свечения — состояние: голубой — жду «Джарвис»; светло-бирюзовый, почти белый — слушаю команду; серый — пауза (микрофон
освобождён); жёлтый — загрузка; красный — проблема со слухом (подробности — в подсказке и в логе).
Фиолетовый — ждёт ответа на вопрос-разрешение. Меню значка: «Пауза», «Обновить команды», «Забыть
разрешения», «Запускать при входе в Windows» (галочка; запись `Jarvis` в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`), «Выход». Запускается только одна копия.

Прочие режимы:

| Команда | Что делает |
|---|---|
| `jarvis --check` | проверка окружения |
| `jarvis --enroll` | запись образца голоса с микрофона |
| `jarvis --set-api-key` / `--forget-api-key` | ключ API нейросети (в Диспетчере учётных данных Windows) |
| `jarvis --ask "вопрос"` | спросить нейросеть текстом и услышать ответ (проверка без микрофона) |
| `jarvis --voice-test` | проверка: 10 раз «Джарвис» как обычно — узнал бы голос и сработал бы детектор; образец не меняется |
| `jarvis --enroll-from a.wav b.wav c.wav` | образец голоса из WAV (по одному «Джарвис» в файле) |
| `jarvis --bench [файлы.wav]` | замеры: «Джарвис» (задержка, нагрузка, сходство голоса) и команды (верно ли и когда решено); без файлов — `tests/fixtures` |
| `jarvis --record out.wav --seconds 5` | отладка: записать, что слышит модель (по умолчанию звук на диск не пишется) |
| `jarvis --say "Добрый вечер, сэр"` | произнести фразу голосом синтеза; `--voice irina` — другим голосом, `--out файл.wav` — сохранить |
| `jarvis --root F:\JARVIS` | явно указать корень проекта |

## Настройка

- `config/default.toml` — значения по умолчанию с комментариями. Лежит в git, не меняйте его.
- `config/user.toml` — ваши изменения: только нужные ключи, в тех же секциях. В git не попадает.

```toml
# config/user.toml
[audio]
input_device = "Fuxi-H3"   # часть имени микрофона; "default" — системный

[wake]
max_edit_distance = 1      # 0 — строже, 2 — чувствительнее
listen_secs = 8

[nlu]
min_score = 0.8            # строже сопоставлять фразы с командами

[speaker]
threshold = 0.45           # или "auto" — подобранный при --enroll
```

С ошибкой в конфиге Джарвис не стартует и пишет, какой параметр неверен и почему.

Логи: `logs/jarvis.ГГГГ-ММ-ДД.log`, ротация раз в сутки. Подробнее: `logging.level = "debug"` или
переменная `RUST_LOG=debug`; что именно распознаётся — `RUST_LOG=info,jarvis_audio=trace`.

## Звуковые пакеты

Пакет — папка в `sounds/` с WAV-файлами и `pack.toml`:

```toml
name = "Мой Джарвис"
[replies]
wake = ["yes_sir.wav", "listening.wav"]     # обязательно: отклик на «Джарвис»
ok = ["done.wav"]                           # «Запрос выполнен, сэр»
not_understood = ["sorry.wav"]              # «Не понял, сэр» (фраза не похожа на команду)
not_heard = ["didnt_hear.wav"]              # «Не расслышал, сэр» (после «Джарвис» — тишина)
failed = ["failed.wav"]                     # «Не удалось, сэр»
ask = ["may_i.wav"]                         # «Сэр, разрешите выполнить?»
denied = ["as_you_wish.wav"]                # «Как скажете, сэр» (после отказа)
out_of_range = ["too_much.wav"]             # «Такое значение недопустимо, сэр» (нет — звучит not_understood)
```

Диалог после «Джарвис»: «Да, сэр» — и 2 секунды (`wake.listen_secs`) ожидания. Понял фразу —
выполняет; услышал, но не понял — `not_understood` и ждёт повтора; ничего не услышал — `not_heard`.
Начатую фразу ожидание не обрывает: пока детектор слышит речь, Джарвис ждёт её конца.

На ответ можно положить несколько вариантов — они чередуются. Тишина по краям файлов обрезается
автоматически. Выбор пакета: `voice.pack` в конфиге. Стандартный пакет сделан голосом Windows
«Pavel»; пересоздать или сделать свой другим голосом: `scripts\generate-voice-pack.ps1 -Voice Irina -Name irina`.

## Голос синтеза

Готовые ответы («Да, сэр», «Запрос выполнен») звучат из звукового пакета — мгновенно. По умолчанию и
вопрос-разрешение — фраза пакета (`ask`), а подробности (какой сайт, скрипт, клавиша) — в окне.
Синтез офлайн (Piper) озвучивает предупреждение о запуске от администратора, а с
`spoken_details = true` — и подробности: «Сэр, команда «громкость на 40» установит громкость.
Разрешить?», «Сэр, вы имели в виду «открой гугл» или «открой яндекс»?».

```toml
# config/user.toml
[voice]
tts = "irina"          # dmitri (по умолчанию), ruslan, denis, irina или "none" — без синтеза
tts_speed = 1.1        # темп 0.5–2
spoken_details = true  # подробности вопроса голосом синтеза (по умолчанию — фраза пакета)

[general]
greet_on_start = false # не здороваться при запуске
```

Приветствие при запуске («Доброе утро, сэр» / «Добрый день» / «Добрый вечер») берётся из секции
`[greetings]` звукового пакета: `morning` (5–11 ч), `day` (12–16), `evening` (17–22), `night`
(23–4; нет — звучит вечернее). Голос Джарвиса для пакета делается скриптами в `tools/voice/`
(см. `tools/voice/README.md`).

Послушать: `jarvis --say "Добрый вечер, сэр" --voice ruslan`. Голоса кроме Dmitri ставит
`scripts\download-models.ps1 -Full`. Без голоса (не скачан, `"none"`) Джарвис работает как раньше —
вопрос звучит фразой `ask` из звукового пакета, подробности — в окне.

Голос занимает около 100 МБ, поэтому держится в памяти, только пока нужен: загружается на
«Джарвис» (пока вы договариваете команду) и выгружается после 30 секунд тишины.

## Нейросеть (свободные вопросы)

«Джарвис, кто такой Тони Старк?» — фраза после «Джарвис», не похожая на команду, уходит в нейросеть
Claude (Anthropic). Ответ звучит **по предложениям по мере прихода** (голосом синтеза), текст —
в окне в правом нижнем углу. Сразу после ответа можно продолжить без «Джарвис» («а подробнее?»);
разговор помнится `llm.memory_mins` минут. Если ответ задерживается — «Секунду, сэр».

Нейросеть может выполнять ваши команды («сделай потише и открой ютуб») — только из списка
команд и через ту же проверку разрешений, что и голосовые. Код она не пишет и не запускает.

Включение:

1. Ключ API: console.anthropic.com → API Keys (нужен пополненный баланс; запросы платные).
2. `jarvis --set-api-key` — вставить ключ (ввод скрыт; ключ хранится в Диспетчере учётных данных
   Windows, не в файлах и не в логах). Удалить: `jarvis --forget-api-key`.
3. В `config/user.toml`:

   ```toml
   [llm]
   enabled = true
   ```

4. Проверка без микрофона: `jarvis --ask "кто такой Тони Старк?"` — печатает ответ, озвучивает,
   показывает задержки. `jarvis --check` — пункт «Нейросеть».

Настройки (`[llm]` в `config/default.toml`): модель (`claude-sonnet-5-5` по умолчанию), усилие
(`low` — быстрее), длина ответа, память разговора, окно. Нет интернета — «Нет связи с сервером,
сэр»; прервать длинный ответ — Ctrl+Alt+F12 или «Пауза» в трее (голосом «стоп» во время ответа не
сработает: пока Джарвис говорит, микрофон заглушён).

**Ключ от посредника** (не `sk-ant-…`, а ключ продавца «для Claude Code / CLI»): в его инструкции
есть `ANTHROPIC_BASE_URL` (адрес) и `ANTHROPIC_AUTH_TOKEN` или `ANTHROPIC_API_KEY` (ключ). Ключ —
так же через `jarvis --set-api-key`, адрес — в `config/user.toml`:

```toml
[llm]
enabled = true
server = "https://адрес-из-ANTHROPIC_BASE_URL"
auth = "bearer"            # если в инструкции ANTHROPIC_AUTH_TOKEN; ANTHROPIC_API_KEY — "api_key"
model = "claude-sonnet-5"  # какую модель открыл продавец
```

Ответ «403: This model is not enabled for the API key» — модель не открыта для ключа: поменяйте
`model`. Посредник видит все вопросы и ответы и может в любой момент перестать работать.

## Как пользоваться

- «Джарвис» → «Да, сэр» → команда: «открой ютуб».
- Можно на одном дыхании: «Джарвис, открой ютуб».
- После команды 12 секунд (`session.follow_up_secs`) можно говорить следующую без «Джарвис»:
  «включи музыку», «громче».
- Непонятная фраза после «Джарвис» — «Не понял, сэр». Если фраза одинаково похожа на две команды —
  «Сэр, вы имели в виду X или Y?»: повторите нужную. Непонятная фраза в режиме ожидания
  следующей команды игнорируется (вдруг это разговор в комнате).
- Команда часто выполняется ещё до конца фразы: когда начало фразы уже однозначно («открой ю…»).

### Разрешения

Перед командой, которую вы ещё не разрешали, Джарвис спрашивает вслух, что именно произойдёт
(«Сэр, команда «открой ютуб» откроет YouTube в браузере. Разрешить?»), и показывает окно с
подробностями: какой сайт, какой скрипт, какая клавиша. Ответьте голосом (когда он договорит) или
кнопкой:

| Ответ | Что будет |
|---|---|
| «да», «разрешаю» | выполнить один раз, в следующий раз спросить снова |
| «всегда», «разрешаю всегда» | выполнить и больше не спрашивать |
| «нет», «отмена» | не выполнять |
| «никогда» | не выполнять и запомнить запрет |
| молчание 10 секунд (после вопроса) | не выполнять |

- Решения хранятся в `config/permissions.toml` (ваш файл, в git не попадает). Пакеты команд выдать
  себе разрешение не могут.
- Разрешение привязано к действию: изменится адрес или путь в команде — Джарвис спросит снова.
- Команды с пометкой `always_ask = true` спрашивают каждый раз; снять пометку можно только вам —
  `allow_always = true` у команды в `permissions.toml`.
- Забыть все разрешения: «Джарвис, забудь разрешения» (с подтверждением) или пункт в трее.

### Аварийная остановка

**Ctrl+Alt+F12** (настраивается: `hotkeys.emergency_stop`) или «Джарвис, стоп» / «хватит»:
Джарвис замолкает, отпускает зажатые клавиши, завершает запущенный скрипт (со всеми его процессами)
и отменяет вопрос.

- **Горячая клавиша** вдобавок ставит слух на паузу (микрофон освобождается). Продолжить — снять
  «Паузу» в трее.
- **Голосом** микрофон не выключается: Джарвис сразу снова откликается на «Джарвис» (иначе из паузы
  голосом не выйти). Чтобы музыку не остановить «стопом» случайно — для неё есть «пауза» /
  «поставь на паузу».

### Журнал действий

`logs/actions.ГГГГ-ММ-ДД.jsonl` — по строке на каждую команду: время, что услышано, какая команда,
уверенность, было ли разрешение и как получено (голосом или кнопкой), результат.

Готовые команды:

| Пакет | Фразы |
|---|---|
| browser | открой ютуб · открой гугл · открой браузер (Firefox) · открой календарь · открой музыку (YouTube Music) |
| media | включи музыку / поставь на паузу · следующий трек · предыдущий трек · громче · тише · громкость на 40 · выключи звук |
| system | заблокируй компьютер · переведи компьютер в сон · перезагрузи компьютер · выключи компьютер · покажи рабочий стол · сделай скриншот · открой параметры |
| apps | открой блокнот · открой калькулятор · открой проводник · открой диспетчер задач · запусти клод · запусти хап |
| examples | запиши отметку хорошее (скрипт со слотом) · режим работы (цепочка) |
| встроенные | стоп · забудь разрешения · обнови команды · режим диалога / закончим диалог |

Сон, перезагрузка и выключение спрашивают разрешение **каждый раз**.

Изменили команды — скажите «Джарвис, обнови команды» или выберите «Обновить команды» в трее:
пакеты перечитаются без перезапуска.

## Как добавить свою команду

Команды — TOML-файлы, код менять не нужно. Пакет — папка в `commands/` с файлом `command.toml`:

```toml
pack = "my"          # имя пакета
version = 1

[[command]]
id = "open_mail"                      # латиница, цифры, _ и -; уникален среди всех пакетов
phrases = ["открой почту", "проверь почту"]
description = "откроет Gmail в браузере"   # читается в вопросе-разрешении: «команда X <description>»
reply = "ok"                          # ответ после успеха: ok, failed, not_understood, not_heard, out_of_range, wake, ask, denied или none
# always_ask = true                   # спрашивать разрешение каждый раз
[command.action]
type = "open_url"
url = "https://mail.google.com"
```

Типы действий:

```toml
# Открыть сайт (только http:// и https://)
[command.action]
type = "open_url"
url = "https://www.youtube.com"
# необязательно: сначала поискать открытую вкладку по заголовку (Firefox) —
# нашлась — переключиться на неё, нет — открыть адрес. «*» — любые символы.
find_tab = ["* - YouTube", "YouTube"]

# Мультимедиа: play_pause, next, previous, stop, volume_up, volume_down, volume_set, mute
[command.action]
type = "media"
operation = "volume_up"
steps = 5            # только для volume_up/down: нажатий по ~2 %, 1–50 (по умолчанию 5)
# для volume_set: level = "40" или слот level = "{level}"

# Сказать готовый ответ из звукового пакета или свой WAV из папки пакета
[command.action]
type = "say"
reply = "ok"         # или: file = "hello.wav"

# Запустить программу и не ждать
[command.action]
type = "launch_app"
path = "C:\\Program Files\\Mozilla Firefox\\firefox.exe"   # или "notepad.exe" (из PATH), или путь внутри пакета
args = ["--private-window"]
# focus = "firefox.exe"   # уже открыта — вывести её окно вперёд вместо нового запуска
# working_dir = "C:\\Users\\me"

# Скрипт из папки пакета: .exe, .bat/.cmd, .ps1, .py — ждёт завершения
[command.action]
type = "run_script"
path = "backup.ps1"
args = ["--full"]
timeout_sec = 30     # 1–3600; дольше — скрипт и все его процессы завершаются

# Клавиша (скан-коды — работает в играх)
[command.action]
type = "key_press"
key = "space"        # a–z, 0–9, f1–f24, space, enter, esc, tab, up/down/left/right, ctrl, shift, alt, win, num0…
hold_ms = 50         # сколько держать (по умолчанию 30)
repeat = 2           # сколько раз (по умолчанию 1)
interval_ms = 100    # пауза между нажатиями (по умолчанию 50)

# Сочетание: нажимаются по порядку, отпускаются в обратном
[command.action]
type = "hotkey"
keys = ["ctrl", "shift", "esc"]

# Питание: lock, sleep, logoff, restart, shutdown (советуем always_ask = true)
[command.action]
type = "system_power"
operation = "lock"

# Цепочка: шаги по порядку, ошибка шага прерывает цепочку
[command.action]
type = "sequence"
[[command.action.steps]]
type = "hotkey"
keys = ["win", "d"]
[[command.action.steps]]
type = "wait"
ms = 400             # до 60 000
[[command.action.steps]]
type = "launch_app"
path = "notepad.exe"

# Дождаться запуска программы (по имени файла), не дольше timeout_sec (1–300);
# не дождались — «Не удалось, сэр». Обычно — шаг цепочки после launch_app.
[command.action]
type = "wait_process"
name = "faceitservice.exe"
timeout_sec = 120

# Спросить и ждать ответа: WAV вопроса из папки пакета, ответы → id команд.
# Ответ ждём, как команду после «Джарвис»: не понял — «Не понял, сэр», тишина —
# «Не расслышал, сэр». Выбранная команда спрашивает своё разрешение.
# В цепочке — только последним шагом.
[command.action]
type = "ask"
file = "game_ask.wav"   # «Во что хотите поиграть, сэр?»
[command.action.choices]
"кс" = "game_cs2"
"контра" = "game_cs2"
```

**Слоты** — параметры из речи. Каждый описан с типом и проверкой, поэтому ослышка не превратится в
непредсказуемую команду. Значения подставляются в `args`, `url` и `level`, но никогда в путь к
программе или скрипту.

```toml
[[command]]
id = "volume"
phrases = ["громкость на {level}", "сделай громкость {level}"]
description = "установит громкость"
[command.slots.level]
type = "number"      # «сорок пять» → 45; вне min–max — «Такое значение недопустимо, сэр»
min = 0
max = 100
clamp = true         # необязательно: вне min–max прижать к границе («громкость на 120» → 100)
[command.action]
type = "media"
operation = "volume_set"
level = "{level}"

[[command]]
id = "site"
phrases = ["открой сайт {site}"]
description = "откроет сайт"
[command.slots.site]
type = "choice"      # как сказано → что подставить (или просто список ["ютуб", "гугл"])
values = { "ютуб" = "youtube.com", "гугл" = "google.com" }
[command.action]
type = "open_url"
url = "https://{site}"
```

Команды со слотами выполняются по концу фразы, а не по её началу: «сорок» ещё может стать «сорок пять».

Скрипты:
- `.ps1` со строками на русском сохраняйте в **UTF-8 с BOM**, иначе Windows PowerShell 5.1 прочитает
  их как ANSI. Скрипт запускается с `-ExecutionPolicy Bypass`, без окна консоли, рабочая папка —
  папка пакета.
- Код возврата не 0 — «Не удалось, сэр», в журнал попадает код и хвост вывода скрипта.
- Изменили скрипт — Джарвис снова спросит разрешение: в отпечаток входит содержимое файла.
- `.py` запускается через `python` из PATH — нужен установленный Python.

Советы по фразам:
- Пишите так, как говорите, по-русски: «открой ютуб», а не «YouTube». Регистр, «ё», знаки
  препинания и слова-паразиты («ну», «пожалуйста») не важны; числа можно словами.
- Порядок слов не важен: «ютуб открой» тоже сработает.
- Две команды с одинаковой фразой — предупреждение в логе и в `jarvis --check`.
- Ошибка в манифесте не ломает остальные: пакет пропускается, в логе — файл, строка и причина.
  Проверка: `jarvis --check` (пункт «Команды»).
- Чтобы потренироваться без последствий — `general.dry_run = true`: команды распознаются и
  пишутся в лог, но не выполняются.

## Решение проблем

| Симптом | Что делать |
|---|---|
| `cargo` не найден | Откройте новый терминал после установки Rustup или добавьте `%USERPROFILE%\.cargo\bin` в PATH. |
| `link.exe not found` при сборке | Не установлены Build Tools с компонентом C++ (шаг 1). |
| Сборка: `SHERPA_ONNX_ARCHIVE_DIR does not contain expected archive` | Сначала `scripts\download-models.ps1` (шаг 2). |
| `--check`: «не скачано» / «нет метки» | `scripts\download-models.ps1` (при повреждении — с `-Force`). |
| `--check`: «цифровая тишина» | Микрофон выключен кнопкой на устройстве или в драйвере; проверьте в «Параметры → Система → Звук». |
| `--check`: микрофон не найден | `audio.input_device` — подстрока имени из списка «устройства ввода». |
| Значок красный «не слышу» | Микрофон отключили — Джарвис сам переподключится, когда он появится. |
| Не реагирует на «Джарвис» | `jarvis --record test.wav`, скажите «Джарвис», затем `jarvis --bench test.wav` — видно, что слышит модель. Если голос не совпал — в логе «сказал не ваш голос»: перезапишите `--enroll` или понизьте `speaker.threshold`. |
| Загрузка модели оборвалась | Запустите скрипт ещё раз — скачивание продолжится. |
| «файл разрешений не читается» | Исправьте `config/permissions.toml` по сообщению или удалите его — Джарвис снова начнёт спрашивать. |
| «горячая клавиша … уже занята» | Её заняла другая программа — выберите другую в `hotkeys.emergency_stop`. |
| `--check`: синтез речи — ошибка `phontab` | Путь к программе с русскими буквами, а короткие имена (8.3) на диске отключены. Установите в папку с латинским путём. |
| Команда не выполняется без вопроса | Это не ошибка: вы ответили «никогда». Скажите «Джарвис, забудь разрешения» или удалите запись в `permissions.toml`. |
