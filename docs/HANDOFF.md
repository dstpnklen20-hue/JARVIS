## Окружение (чтобы не искать заново)

- Rust: если `cargo` не находится — `$env:Path = "$env:USERPROFILE\.cargo\bin;$env:Path"`.
- Python 3.12 (winget, user scope). Окружения в `tools/voice/`: `.venv` (audio-separator, оценки),
  `.venv-enhance` (ClearerVoice), `.venv-tts` (Chatterbox, не используется), `.venv-f5` (ESpeech).
  PyTorch везде **cu128** (RTX 50-й серии); установщики иногда ставят CPU-torch — вернуть
  `pip install --force-reinstall --no-deps torch torchaudio torchvision --index-url https://download.pytorch.org/whl/cu128`.
- ffmpeg (winget Gyan.FFmpeg) не в PATH старых терминалов — путь ищется в
  `%LOCALAPPDATA%\Microsoft\WinGet\Packages\Gyan.FFmpeg*\...\bin`.
- torchaudio ≥ 2.9 читает файлы через torchcodec (нужны DLL FFmpeg) — в `clone_f5.py` чтение
  подменено на soundfile.
- Микрофон ME6S, наушники Fuxi-H3 (вывод по умолчанию). Образец вашего голоса — `data/voiceprint.json`.
