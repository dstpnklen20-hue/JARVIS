# Команды Джарвиса

Все голосовые команды: встроенные в ядро и из пакетов `commands/*/command.toml`.
Обновлено: 2026-10-15.

## Как говорить

- **«Джарвис, <команда>»** — одной фразой, или «Джарвис», пауза, ответ «Да, сэр», затем команда
  (на её начало — 3,5 с; пока вы говорите, Джарвис ждёт конца фразы).
- «Джарвис» срабатывает только **в начале фразы** — посреди вашей речи («…и тут я говорю: Джарвис»)
  он не отзывается. Откликается только на ваш голос (образец — `jarvis --enroll`).
- После команды несколько секунд можно сказать следующую без «Джарвис».
- Любая фраза, не похожая на команду, уходит нейросети (если она включена, раздел «Нейросеть»).
- Новая команда в первый раз спрашивает разрешение: «да» — один раз, «всегда» — запомнить,
  «нет», «никогда» — запомнить запрет; тишина 10 с — не выполнять.
- Свои команды — в главном окне («Команды» → «+ Новая») или в `commands/my/command.toml`
  (формат — в [README](../README.md#как-добавить-свою-команду)); «Джарвис, обнови команды» — без перезапуска.

## Встроенные

| Что делает | Фразы |
|---|---|
| Остановить всё и слушать дальше — в том числе ответ нейросети, пока Джарвис говорит | стоп, стой, хватит, замолчи, помолчи, умолкни, отбой, остановись, прекрати |
| Отключиться: не отзываться даже на «Джарвис», но остаться открытым (включить — щелчок по реактору в главном окне или «Пауза» в трее) | отключись, отключайся, засыпай, спать, иди спать, режим сна, перестань слушать |
| Закрыть окно ответа нейросети (или двойной / правый щелчок по окну, крестик) | закрой ответ, закрой окно ответа, убери ответ, убери окно, скрой ответ |
| Режим диалога — команды без «Джарвис» | режим диалога, включи режим диалога, перейди в режим диалога, давай поговорим |
| Выйти из режима диалога (сам — через 10 мин без команд) | закончим диалог, конец диалога, выйди из режима диалога, выключи / отключи режим диалога |
| Перечитать команды | обнови команды, перезагрузи команды, обнови список команд |
| Забыть все разрешения (с подтверждением) | забудь разрешения, сбрось разрешения, забудь все разрешения |
| Аварийная остановка: отпустить клавиши, прервать всё, выключить микрофон | **Ctrl+Alt+F12** |

**Ответы на вопрос-разрешение:** один раз — да, разрешаю, давай, можно, выполняй, конечно, хорошо,
ок, согласен, действуй; запомнить — всегда, навсегда, постоянно; отказ — нет, отмена, запрещаю,
нельзя, «не …»; запретить навсегда — никогда, ни за что.

## Программы — `commands/apps`

| Что делает | Фразы |
|---|---|
| Блокнот | открой / запусти блокнот |
| Калькулятор | открой / запусти калькулятор |
| Проводник | открой проводник, покажи файлы |
| Диспетчер задач | открой / запусти диспетчер задач, диспетчер задач |
| Claude (приложение из Microsoft Store) | запусти / открой клод, запусти / открой клоуд |

**Закрыть программу:** «закрой …» так же, как открывали — «закрой блокнот», «закрой калькулятор»,
«закрой клод», «закрой браузер». Закрывает окна, как крестиком: программа может спросить о сохранении,
свёрнутая в трей остаётся в трее, принудительно ничего не завершается. Проводник (он же панель задач)
закрыть нельзя. Своим программам — `close = true` в манифесте или галочка в редакторе команд.

## Нейросеть (если включена)

- Любой вопрос после «Джарвис»: «Джарвис, кто такой Тони Старк?» — ответ голосом и в окне с текстом.
- Уточнение без «Джарвис»: «а подробнее?».
- Команды через нейросеть: «Джарвис, сделай потише и открой ютуб» — выполнит обе (через разрешения).
- Прервать ответ — «стоп» (слышит и пока говорит), закрыть окно — «закрой ответ».
